## 🔧 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/gauravttiwari/my-portfolio.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd my-portfolio
   ```

3. **Open in your preferred browser**
   ```bash
   # Simply open index.html in any modern web browser
   # Or use a local server for development
   ```

4. **For development with live server (optional)**
   ```bash
   # Using Python's built-in server
   python -m http.server 8000
   
   # Using Node.js live-server
   npx live-server
   ```

## 🚀 Usage

### Viewing the Portfolio
1. Open `index.html` in a modern web browser
2. Navigate through different sections using the top navigation
3. Explore interactive elements and 3D animations
4. View project details and download resume

### Customization
1. Update personal information in `index.html`
2. Replace images in the `assets/` folder
3. Modify color schemes in the Tailwind configuration
4. Add or remove projects in the projects section
